# WS12 API contract (Sprint 2)

The interface between the app (`src/`) and Supabase (`supabase/`). The backend owns this file and keeps it in step with the migrations and edge functions. The frontend calls only what is listed here.

Errors: every function raises a Postgres exception whose message is one of the stable codes below, so the app can map it to a translated message. The one exception is `redeem_invite`, which returns some codes in a column (see its row). Edge functions return JSON `{ "error": "<code>" }` with a 4xx status. Since Sprint 2 the Sprint 1 functions (`declare_age`, `claim_parent_role`, `request_consent`, `give_consent`, `withdraw_consent`, `accept_link`, `remove_link`, `parent_learner_summary`) and the profile consent check also raise these codes.

Stable error codes: `not_signed_in`, `consent_required`, `not_allowed`, `invalid_input`, `invalid_code`, `code_expired`, `rate_limited`, `already_linked`, `email_not_verified`, `contact_mismatch`, `consent_expired`, `not_found`.

`p_answers` for `save_onboarding`:

```json
{
  "first_name": "Thabo",
  "grade": 12,
  "school_id": "uuid or null",
  "school_name_other": "text or null",
  "province": "GP",
  "subjects": [{ "code": "MATH", "target_mark": 70 }],
  "exam_dates": [
    { "kind": "trial", "date": "2027-08-23" },
    { "kind": "final", "date": "2027-10-25" }
  ],
  "study_days": ["mon", "tue", "wed", "thu", "fri"],
  "study_bands": ["afternoon", "evening"],
  "goal": "Pass Maths with 70 percent",
  "career_interests": ["engineering"]
}
```

Field rules for `p_answers`: `first_name` 1 to 60 characters after trimming, no control characters. `grade` the number 11 or 12. `school_id` null or an existing school id; `school_name_other` null or up to 120 characters; not both. `province` one of `EC`, `FS`, `GP`, `KZN`, `LP`, `MP`, `NC`, `NW`, `WC`. `subjects` up to 20 objects with exactly `code` (an existing subject code, no repeats) and `target_mark` (null or a whole number 0 to 100). `exam_dates` up to 2 objects with exactly `kind` (`trial` or `final`, no repeats) and `date` (a real `YYYY-MM-DD` date from last year to three years ahead); the trial must be before the final. `study_days` distinct values from `mon` to `sun`. `study_bands` distinct values from `morning`, `afternoon`, `evening`, `late`. `goal` null or up to 200 characters. `career_interests` distinct values from the chip list in `src/domain/onboarding.ts`. Arrays may be empty.

## Called only by edge functions

| Function                | Called with             | Purpose                                                                                                                                                                         |
| ----------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `library_download_path` | the caller's session    | Returns the storage path of a file the caller may download; `not_found` or `not_allowed` otherwise.                                                                             |
| `store_consent_contact` | service role            | Stores the encrypted parent contact for a pending request, expiring 30 days after the request.                                                                                  |
| `record_payment`        | service role            | Records one verified payment event in one transaction. Returns `recorded`, `duplicate`, `amount_mismatch`, `unknown_product`, `unknown_purchase`, `ignored` or `invalid_input`. |
| `run_housekeeping`      | service role or pg_cron | Daily: closes requests older than 30 days, deletes stored contacts that are no longer needed and invite attempts older than a day.                                              |

## Direct table access (RLS enforced)

- `profiles`: select and update own row (first name, grade, school, province, language). Learner data needs consent.
- `learner_subjects`, `learner_exam_dates`, `learner_preferences`: select, insert, update, delete own rows, consent required.
- `schools`, `subjects`, `exam_dates`: read for every signed-in person.

## Edge functions (call with `supabase.functions.invoke`)

| Function           | Body                                       | Returns                                   | Notes                                                                                                                                                                                                                                                                           |
| ------------------ | ------------------------------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `request-consent`  | `{ "channel": "email", "contact": "..." }` | `{ "consent_id": "uuid", "sent": false }` | Stores the contact encrypted for 30 days. Sending real messages is switched off until Didi approves (`CONSENT_SENDING_ENABLED` is not set), so `sent` is false. Only `email` for now; `sms` gives `invalid_input`.                                                              |
| `library-download` | `{ "file_id": "uuid" }`                    | `{ "url": "...", "expires_in": 300 }`     | Checks the entitlement, returns a short-lived signed link. `not_allowed` with `purchase_ref` (the latest purchase reference, or null) when the check fails; `not_found` for an unknown file.                                                                                    |
| `payfast-itn`      | PayFast ITN form post                      | `200` text `OK`                           | Server to server only. Verifies source IP, signature with the passphrase, merchant id, amount (must equal `products.price_cents`) and the PayFast validate call. Sandbox only (`503` otherwise). Refusals are `400` or `403` text.                                              |
| `stripe-webhook`   | Stripe event                               | `200` JSON                                | Server to server only. Verifies the `Stripe-Signature` header (300 second tolerance) and refuses live mode events. Test mode only (`503` otherwise). Refusals are `400` with `invalid_signature`, `live_mode_refused`, `invalid_input`, `amount_mismatch` or `unknown_product`. |
