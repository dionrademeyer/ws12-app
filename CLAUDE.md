# WS12 App - Rules for Claude and the agent team

WS12 (Winning Strategies for Grade 12) is a learner app built on the book by Melvin Monroe Tobias. Didi is the product and creative partner and the final approver.

## Source of truth (read before any work)

1. `docs/product-bible.md` - what we are building, screen by screen (written in Sprint 0)
2. `docs/build-brief.md` - the Master Build Prompt
3. `docs/build-plan.md` - architecture and the 7 sprints
4. `docs/decisions.md` - decisions already made; never reopen them without Didi
5. `SPRINTS.md` - the tracker: current sprint, acceptance criteria, status

If these disagree, the order above wins. If something is still unclear, add it to "Needs from Didi" in `SPRINTS.md` and keep going on what is clear.

## The agent team (`.claude/agents/`)

- `ws12-product-lead` - runs each sprint: plans, delegates, updates `SPRINTS.md`, writes the report
- `ws12-supabase` - database schema, Row Level Security, auth, edge functions, payments webhooks
- `ws12-frontend` - React, TypeScript, Tailwind screens and components, mobile first
- `ws12-ai` - AI service layer, recommendation engine ("Your Next Win"), AI Tutor, knowledge base
- `ws12-qa` - independent reviewer: tests, accessibility, security, copy rules; signs off or sends work back

A sprint is only DONE when `ws12-qa` has signed off every acceptance criterion in `SPRINTS.md`.

## Non-negotiable rules

- **Copy:** never use the ampersand character (write "and") and never use em or en dashes (use a hyphen or rephrase). Applies to UI text, docs and commit messages.
- **Bilingual:** all learner-facing text goes through the i18n layer with English and Afrikaans strings. Afrikaans product name: "Wenner Strategieë vir Graad 12".
- **The book is 100% human-written** by a South African educator. AI assists learners, teachers and parents and never replaces them. Never describe the book or Melvin's content as AI-generated.
- **No invented educational content.** The AI Tutor answers from approved WS12 content. Never fabricate lessons, quotes, statistics or testimonials.
- **Privacy:** most learners are under 18. POPIA applies: collect only what is needed, parental consent for minors, RLS on every table, no secrets in client code.
- **Navigation:** no hamburger menu unless Didi approves one in `docs/decisions.md`. Secondary links (Profile, Settings, Help, Logout) open from the profile avatar.
- **Mobile first:** must be excellent at 360px wide and on slow connections.
- **Clean, human-looking code:** run Prettier on every change, no AI-marker comments ("Generated by", "As an AI"), no leftover placeholder comments, meaningful names. (Didi also checks code in codebeautify.org.)
- **Small, safe steps:** commit per feature with a clear message. If a change breaks rendering, revert to the last working commit immediately instead of patching on top.

## Stack

React + TypeScript + Vite + Tailwind, Supabase (auth, Postgres, storage, edge functions), PWA first, Expo later. Payments: PayFast and Stripe. Hosting: app on a subdomain (e.g. app.winstrat12.co.za); the marketing site stays on Gary's hosting.

## What agents must never do without Didi

Go live, take real payments, delete data or repos, email or message real users, change pricing, or publish content as Melvin's.
